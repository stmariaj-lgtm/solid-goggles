# Дев’ятий вимір — Python-сайт

Підготовлений код. Сайт ще не опубліковано; реальну доставку листа не перевірено.

Python 3.12 + Flask. Сторінка з магом, трьома персонажами, словом «бурмалда» та рибою. Після підтвердження Python надсилає лист через Resend; фінал відкривається лише після прийняття запиту поштовим сервісом. Прийняття сервісом не гарантує потрапляння у «Вхідні»: перевірте доставку і спам окремо.

## Локальний запуск

```
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

Відкрити http://127.0.0.1:8000 у браузері. Сам HTML-файл не відкривати: він потребує Python-сервера.

## Публікація на Render

Код потрібно розмістити в Git-репозиторії, доступному вашому Render.
Створити Python Web Service. Build: `pip install -r requirements.txt`.
Start: `gunicorn --workers 1 --threads 4 --timeout 45 --bind 0.0.0.0:$PORT app:app`.
Health check: `/health`.
У секретних змінних середовища налаштувати:

- SECRET_KEY — довгий випадковий секрет, постійний між перезапусками.
- RESEND_API_KEY — ключ Resend з правом надсилання, лише на сервері.
- MAIL_TO — st.mariaj@gmail.com.
- MAIL_FROM — підтверджений відправник Resend.

Тестовий відправник onboarding@resend.dev може надсилати лише на адресу власника акаунта Resend. Для цього зареєструйте Resend на st.mariaj@gmail.com. Для інших адрес або постійного власного відправника потрібен підтверджений домен. Ключі не вставляти у HTML, Git чи чат.

На сторінці немає згадок ШІ. Дрібна примітка повідомляє про передачу обраного персонажа авторці. Жодні ім’я, адреса гравця чи контакти не запитуються. Хостинг може вести стандартні журнали запитів.

Озвучення залежить від українських голосів браузера. Помилка звуку не блокує надсилання. Фраза про наступний лист — частина сюжету: цей сайт не надсилає гравцеві запрошення і не збирає його пошту.

Повтор після помилки використовує той самий ключ ідемпотентності Resend. Не оновлюйте сторінку між повторними спробами, щоб не створити новий код проходження. Захист від спаму розрахований на невелику приватну відкритку, не публічну масову кампанію. Працювати з одним процесом, як у наведеній команді.

## Перевірка

`python -m unittest -q`

Тести перевіряють три персонажі, неправильне слово, підроблений токен, сторінку та недоступну пошту. Вони замінюють поштовий виклик тестовим і не надсилають реальні листи.
